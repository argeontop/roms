# Outils E01 optionnels

Placer ici `ewfacquirestream.exe` et `ewfexport.exe`, accompagnés de leurs DLL.
Ils doivent provenir d'une construction Windows x64 de libewf avec zlib.

Les binaires sont exclus de Git. Voir le README principal pour les sources
officielles, la procédure de configuration et le contrôle aller-retour préalable.
